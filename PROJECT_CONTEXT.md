## Key decisions — carried forward
- **Phase A progression:** No score gates. Auto-advance after 3 sessions.
- **TWA approach for Google Play:** Bubblewrap CLI wraps the existing PWA. Needs: 512×512 icon, assetlinks.json, signed AAB.
- **Home learner auth pattern:** email = `home-{6digitPIN}@wrife.school`, password = PIN. 6-digit PIN generated by `create-child-profile` Edge Function. PIN shown once in a modal on ParentPage.
- **Home learner level storage:** `pwp_pupil_levels.class_id IS NULL` for home learners. Partial unique index `(pupil_id) WHERE class_id IS NULL` prevents duplicates.
- **create-child-profile Edge Function fix (Session 26):** Must use `.update().eq('id', newUserId)` NOT `.upsert()` — the upsert INSERT path fails on NOT NULL `email` constraint before conflict detection fires. The `handle_new_user` trigger already inserts the profile row with email, so an UPDATE is correct.
- **profiles_role_check fix (Session 26):** Migration `20260506000001_add_parent_role.sql` added 'parent' to the CHECK constraint. Without this, parent signup fails with "Database error saving new user".
- **Pupil auth:** `pupil-login` Edge Function — takes classCode + username + PIN, bcrypt.compareSync (NOT async), auto-provisions auth.users entry, returns JWT. Frontend calls `supabase.auth.setSession()`.
- **Home learner login:** Uses `supabase.auth.signInWithPassword({ email: home-{PIN}@wrife.school, password: PIN })` — direct Supabase auth, no Edge Function needed.
- **Connect Grid → Writing Studio flow (Session 28):** ParagraphPage checks `writing_studio_unlocked` after submission and routes to `/studio` with `gridSession` in nav state when unlocked. WritingStudioPage reads this and shows anchor sentence banner + plan, locks genre selector, and uses grid context as fallback prompt text.
- **Teacher programme settings (Session 28):** `ProgrammeSettingsPanel` component added inside class detail view in TeacherPage. W-level (W1–W6) and active genre buttons with save; locked W-levels show scaffold complexity hint. Updates `classes.w_level` and `classes.active_genre` via Supabase.
- **`/practice` home learner fix (Session 28):** `useFormulaLevel` now uses `.maybeSingle()` and auto-inserts a `formula_progress` row with defaults if none exists. RLS already allows `auth.uid() = pupil_id` INSERT so this works client-side.
- **parent_pupil RLS fix (Session 27):** Table had RLS enabled but zero policies — all client SELECTs returned empty silently. Added "Parents can read own links" (parent_id = auth.uid()) and "Parents can read linked pupil profiles" (EXISTS subquery via parent_pupil). Service role (Edge Functions) bypasses RLS so inserts were always fine.
- **RLS recursion fix:** is_school_admin() SECURITY DEFINER + own-row policies.
- **parseSentence morphology:** -ing, -ed, -ies, -es (base in COMMON_VERBS), -s/-es rules (Session 25).
- **Anchor→topic sentence:** Chain anchor sentence flows ConnectGridPage → ParagraphPage via `state.gridSession.anchorSentence`.
- **Admin/teacher login (BUG-006 fixed):** Removed `async` from onAuthStateChange callback.
