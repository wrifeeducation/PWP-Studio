## Key decisions — carried forward
- **Phase A progression:** No score gates. Auto-advance after 3 sessions.
- **TWA approach for Google Play:** Bubblewrap CLI wraps the existing PWA. Needs: 512×512 icon, assetlinks.json, signed AAB.
- **Home learner auth pattern:** email = `home-{6digitPIN}@wrife.school`, password = PIN. 6-digit PIN generated by `create-child-profile` Edge Function. PIN shown once in a modal on ParentPage.
- **Home learner level storage:** `pwp_pupil_levels.class_id IS NULL` for home learners. Partial unique index `(pupil_id) WHERE class_id IS NULL` prevents duplicates. Upsert uses SELECT+UPDATE/INSERT (not onConflict) because NULL values can't be matched by Postgres onConflict.
- **Pupil auth:** `pupil-login` Edge Function — takes classCode + username + PIN, bcrypt.compareSync (NOT async — Deno Deploy has no Web Worker), auto-provisions auth.users entry, returns JWT. Frontend calls `supabase.auth.setSession()`. ProtectedRoute checks Supabase session (not localStorage).
- **RLS recursion fix:** is_school_admin() SECURITY DEFINER + own-row policies.
- **Admin email allowlist:** ['mankrah@kafed.org.uk', 'wrife.education@gmail.com', 'miyk99@gmail.com', 'admin@wrife-test.com']
- **Pedagogical foundation:** Deliberate practice (Ericsson). Assessment = exact word class COUNT, not quality. See docs/WriFe-PWP-Development-Spec.docx §1.
- **Formula chain (COMPLETE):** CL1–CL11 rewritten. Verb phrases = single VERB slot. No AUXILIARY_VERB enum. CL4 = properNounSubject flag. CL11 = freeArrangement.
- **parseSentence morphology:** -ing, -ed, -ies, -es (base in COMMON_VERBS), -s (base in COMMON_VERBS). The -s/-es rules were added in Session 25 — without them "grows", "flows" etc. tag as NOUN.
- **SubjectType:** default 'thing' ("Choose a place or thing"). Teacher can set 'person' or 'place' via `subjectType` prop.
- **Diff badges:** `formula.newElement` shown on each ChainRow header. Also shown in SessionComplete growing sentence panel.
- **Compound/complex:** CL9+ pupils see CompoundBuilder after chain. Default `allowedTypes=['coordinating']`. `strictPunctuation=false` by default.
- **Connect Grid:** 3-column planner (topic sentence / Mc plot / events). Column 2 always impersonal with "Mc" placeholder. Anchor sentence auto-seeds Col 1. Genre-specific row labels. W-level (1–6) governs row count, scaffolding and anchor lock. Teacher sets w_level and active_genre per class.
- **Anchor→topic sentence:** Chain anchor sentence flows ConnectGridPage → ParagraphPage via `state.gridSession.anchorSentence` (fixed Session 25 — ParagraphPage was reading `state.leadSentence` only).
- **Admin/teacher login (BUG-006 fixed):** Removed `async` from onAuthStateChange callback to prevent Supabase Web Lock race. AdminLoginPage is self-sufficient: 250ms delay then direct DB fetch after signInWithPassword.
- **Back to WriFe navigation:** "← wrife.co.uk" link in TeacherPage and AdminPage headers. "← WriFe" pill in DashboardPage top bar. All link to https://wrife.co.uk.
